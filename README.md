# Elum | Velas & Aromas

Site institucional e interativo da Elum: velas aromáticas, difusores e home sprays feitos à mão em Itu/SP.

- Teste "Descubra seu aroma"
- Catálogo de 20 aromas com filtros por família e produto
- Montador de kit com envio do pedido pelo WhatsApp
- Coleção Natal de Luz com contagem regressiva das encomendas
- Formulário de encomendas personalizadas e brindes
- Modo "luz de vela" (tema escuro)

HTML estático, sem dependências. Publicado via GitHub Pages.
